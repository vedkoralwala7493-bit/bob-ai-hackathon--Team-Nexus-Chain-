# Setup Guide

> This guide explains how to set up and run the ChainGuard AI prototype locally.

---

## Prerequisites

Before you begin, ensure you have the following:

- A modern web browser such as Google Chrome, Microsoft Edge, Safari, or Firefox
- A code editor such as Visual Studio Code
- Git (optional, only required if cloning the repository using Git)

No Python, Node.js, Docker, PostgreSQL, or additional package installation is required for the current prototype.

---

## Environment Variables

The current ChainGuard AI prototype does not require any environment variables.

No API keys or database credentials are required to run the current frontend prototype.

For future integrations involving external routing services, IBM Bob, backend APIs, databases, or other cloud services, credentials should be stored securely using environment variables and must not be committed to the public repository.
